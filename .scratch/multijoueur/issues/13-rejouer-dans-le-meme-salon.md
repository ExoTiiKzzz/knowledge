# 13 — Rejouer dans le même salon, réglages modifiables

**What to build:** enchaîner devient le geste le plus simple. À la fin d'une **partie**, l'hôte
relance sans repartager le code, et peut changer les réglages entre deux parties pour passer des
drapeaux aux capitales ou d'un continent à l'autre. Le **salon** garde la trace des parties déjà
jouées, afin de savoir qui mène sur la soirée. Un joueur arrivé en retard rejoint entre deux
parties sans déranger.

**Blocked by:** 08 — Enchaîner la série jusqu'au classement final.

**Status:** done

- [ ] L'hôte relance une partie depuis l'écran de fin, sans repartager le code
- [ ] Les réglages sont modifiables entre deux parties
- [ ] Le salon liste les parties déjà jouées et leur vainqueur
- [ ] Un joueur peut rejoindre le salon entre deux parties et jouer la suivante
- [ ] Les scores repartent de zéro à chaque nouvelle partie
- [ ] Le meilleur score solo reste inchangé, quel que soit le nombre de parties enchaînées
